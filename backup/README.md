# project.md 백업 규칙

루트의 `project.md`가 현재 프로젝트 상태를 나타내는 단일 기준 문서다.

큰 범위 변경으로 이전 상태를 보존해야 할 때 기존 문서를 이 폴더에 다음 형식으로
옮긴다.

```text
project-YYYY-MM-DD-vN.md
```

현재 백업:

- `project-2026-08-11-legacy-tgam-eeg-webviz.md`: 기존 `TGAM-EGG-WebViz`의
  Node SerialPort/WebSocket 중심 초기 계획 문서

README나 `PROCESSING.md`처럼 역할이 다른 문서는 이 폴더로 이동하지 않는다.
